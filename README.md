# Zdrowe Stopy - Specjalistyczny Gabinet Podologiczny

Profesjonalna strona internetowa gabinetu podologicznego zbudowana w oparciu o framework **Astro 6.x** oraz **Tailwind CSS**.

## 📖 Dokumentacja i Instrukcja Obsługi

Pełna, szczegółowa instrukcja obsługi strony (edycja treści, dodawanie zdjęć, instalacja na serwerze) znajduje się w pliku:
👉 **[INSTRUKCJA_OBSLUGI.html](./INSTRUKCJA_OBSLUGI.html)** (Otwórz w przeglądarce)

---

## 🚀 Szybki start (Dla deweloperów)

### 1. Instalacja
```bash
npm install
```

### 2. Rozwój lokalny
```bash
npm run dev
```

### 3. Budowanie wersji produkcyjnej
```bash
npm run build
```

## 🛠 Technologie
- **Astro** - Static Site Generator
- **Tailwind CSS** - Stylizacja
- **ProAssist** - Integracja rezerwacji online
- **Schema.org** - Optymalizacja pod wyszukiwarkę Google

## 📁 Struktura projektu
- `/src/pages/` - Podstrony serwisu (treści)
- `/src/components/` - Komponenty interfejsu (Menu, Stopka)
- `/src/assets/` - Zdjęcia i style
- `/public/` - Pliki statyczne (favicon)
